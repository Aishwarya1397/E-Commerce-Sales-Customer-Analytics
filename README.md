#  E-Commerce Sales & Customer Analytics Dashboard

An end-to-end Data Analytics project that analyzes customer purchasing behavior using **Python**, **SQL**, and **Power BI**. The project demonstrates the complete analytics workflow—from data exploration and SQL-based business analysis to an interactive executive dashboard with actionable business insights.

---

##  Project Overview

This project analyzes an e-commerce customer shopping dataset containing **3,900 customer transactions**. The objective is to identify sales trends, customer purchasing behavior, product performance, and marketing effectiveness through data-driven analysis.

The project follows a complete analytics pipeline:

- Data Cleaning & Exploratory Data Analysis (Python)
- Business Analysis using SQL
- Interactive Dashboard Development in Power BI
- Executive Summary with Strategic Recommendations

# Key Insights

- Generated **$233.08K** in revenue from **3,900 transactions**.
- Clothing contributed the highest share of total revenue.
- Fall recorded the highest seasonal sales.
- 57% of purchases used promotional codes.
- Medium (M) was the highest-performing product size.
- Customer purchasing patterns indicate strong engagement with promotional campaigns.

---

# Business Recommendations

- Increase inventory for high-performing product categories.
- Optimize seasonal inventory planning.
- Expand customer loyalty initiatives.
- Continue targeted promotional campaigns.
- Prioritize high-demand product sizes and colors.
